# ΟΚΤΩ · Σχολή Χορού — ιστότοπος

Στατικός ιστότοπος για σχολή χορού στην Αθήνα, φτιαγμένος με
[Eleventy (11ty)](https://www.11ty.dev/) v3.

> **Όλο το περιεχόμενο είναι εικονικό.** Ονόματα, κείμενα, τιμές, τηλέφωνα,
> διευθύνσεις και εικόνες είναι επινοημένα, ώστε ο ιστότοπος να φαίνεται και να
> δοκιμάζεται σαν αληθινός. Στον πίνακα «Πού αλλάζω τι» παρακάτω φαίνεται
> ακριβώς ποιο αρχείο αντικαθιστά το καθένα.

---

## Γρήγορη εκκίνηση

Χρειάζεται **Node.js 18 ή νεότερο** (δοκιμασμένο σε 18.19).

```bash
npm install        # μία φορά
npm start          # τοπικός διακομιστής στο http://localhost:8080
```

Ο διακομιστής παρακολουθεί τα αρχεία: κάθε αλλαγή που αποθηκεύεις εμφανίζεται
αμέσως στον browser, χωρίς ανανέωση.

| Εντολή           | Τι κάνει                                                       |
| ---------------- | -------------------------------------------------------------- |
| `npm start`      | Τοπικός διακομιστής με αυτόματη ανανέωση                       |
| `npm run build`  | Χτίζει τον τελικό ιστότοπο στον φάκελο `_site/`                |
| `npm run images` | Ξαναφτιάχνει τις προσωρινές εικόνες (βλ. «Εικόνες»)            |

Ο φάκελος `_site/` παράγεται αυτόματα — δεν τον επεξεργαζόμαστε ποτέ με το χέρι.

## Πού αλλάζω τι

| Θέλω να αλλάξω…                          | Άνοιξε αυτό                                    |
| ---------------------------------------- | ---------------------------------------------- |
| Όνομα σχολής, σύνθημα, έτος ίδρυσης      | `src/_data/site.js`                            |
| Διεύθυνση, τηλέφωνα, email, social       | `src/_data/site.js`                            |
| Ωράριο γραμματείας                       | `src/_data/site.js` → `hours`                  |
| Ώρες μαθημάτων, αίθουσες, επίπεδα        | `src/_data/schedule.js` → `sessions`           |
| Τιμές συνδρομών και εκπτώσεις            | `src/_data/pricing.js`                         |
| Συχνές ερωτήσεις                         | `src/_data/faq.js`                             |
| Λεζάντες φωτογραφιών                     | `src/_data/gallery.js`                         |
| Κείμενο ενός μαθήματος                   | `src/mathimata/<slug>.md`                      |
| Βιογραφικό καθηγητή                      | `src/kathigites/<slug>.md`                     |
| Κείμενα αρχικής σελίδας                  | `src/index.njk`                                |
| Κείμενα σελίδας «Η σχολή»                | `src/i-sxoli.njk`                              |
| Χρώματα, γραμματοσειρές, αποστάσεις      | `src/assets/css/main.css` → ενότητα 1 (tokens) |
| Σειρά και ονόματα στο μενού              | `eleventyNavigation` στο front matter κάθε σελίδας |
| Φωτογραφίες                              | `src/assets/img/` (βλ. παρακάτω)               |

### Πώς συνδέονται τα δεδομένα μεταξύ τους

Το πρόγραμμα δεν επαναλαμβάνει ονόματα· αναφέρεται σε μαθήματα και καθηγητές με
το **slug** τους, δηλαδή με το όνομα του αρχείου τους:

```
src/mathimata/latin.md            →  slug: "latin"
src/kathigites/marina-kostea.md   →  slug: "marina-kostea"

src/_data/schedule.js
  { day: "fri", start: "19:00", end: "20:15",
    class: "latin", teacher: "marina-kostea", level: "ola", room: "Α" }
```

Έτσι, αλλάζοντας τον τίτλο ενός μαθήματος σε ένα σημείο, αλλάζει παντού.
**Αν αλλάξεις όνομα αρχείου, άλλαξε και το `slug` μέσα του** — και αντίστροφα.

## Πώς προσθέτω κάτι καινούριο

### Νέο μάθημα

1. Φτιάξε το `src/mathimata/<slug>.md` (λατινικό όνομα αρχείου, π.χ. `swing.md`).
2. Αντίγραψε το front matter από ένα υπάρχον μάθημα και συμπλήρωσέ το.
   Κράτα το `slug` ίδιο με το όνομα του αρχείου.
3. Πρόσθεσε τις ώρες του στο `src/_data/schedule.js`.
4. Βάλε εικόνα στο `src/assets/img/classes/<slug>.svg` (ή `.jpg`).

### Νέος καθηγητής

Ίδια διαδικασία στο `src/kathigites/`, με εικόνα στο `src/assets/img/teachers/`.

### Νέα ανακοίνωση

Φτιάξε `src/nea/<slug>.md` με `title`, `date`, `image`, `excerpt`. Εμφανίζεται
αυτόματα πρώτη στη λίστα — τα άρθρα ταξινομούνται με ημερομηνία, νεότερα πρώτα.

## Εικόνες

Δεν υπάρχουν πραγματικές φωτογραφίες, οπότε όλες οι εικόνες είναι **SVG που
παράγονται τοπικά** από το `tools/generate-images.mjs`. Το θέμα τους είναι η
φωτογραφία πολλαπλής έκθεσης: η ίδια φιγούρα σε διαδοχικές στιγμές μιας κίνησης.

Για να μπουν οι αληθινές φωτογραφίες:

1. Βάλε τα αρχεία στους ίδιους φακέλους με τα ίδια ονόματα
   (`src/assets/img/classes/latin.jpg` κ.ο.κ.).
2. Άλλαξε την κατάληξη `.svg` σε `.jpg`:
   - στο front matter κάθε μαθήματος/καθηγητή (πεδίο `image`)
   - στο `src/_data/gallery.js` (πεδίο `file`)
   - στο `src/index.njk` και `src/i-sxoli.njk` (`hero.svg`, `studio.svg`)
3. Διόρθωσε τα `width` / `height` στα `<img>` αν αλλάξουν οι αναλογίες.

Κάθε εικόνα έχει ήδη σταθερές αναλογίες μέσω CSS (`aspect-ratio` + `object-fit`),
οπότε η αντικατάσταση δεν χαλάει τη διάταξη.

Το `tools/generate-images.mjs` **δεν** τρέχει κατά το build· είναι βοηθητικό.
Όταν μπουν οι πραγματικές φωτογραφίες, μπορεί να διαγραφεί.

## Τι μένει πριν ανέβει στο διαδίκτυο

| Εκκρεμότητα         | Πού                                                                  |
| ------------------- | -------------------------------------------------------------------- |
| Πραγματικά στοιχεία | `src/_data/site.js` (τώρα: εικονικά τηλέφωνα και διεύθυνση)           |
| Διεύθυνση ιστότοπου | `src/_data/site.js` → `url` (τώρα: `http://localhost:8080`)           |
| Φόρμα επικοινωνίας  | `src/epikoinonia.njk` — το `action="#"` θέλει υπηρεσία αποστολής      |
| Χάρτης              | `src/epikoinonia.njk` — αντικατάσταση του `.map-placeholder`          |
| Φωτογραφίες         | `src/assets/img/`                                                    |
| Σύνδεσμοι social    | `src/_data/site.js` → `social` (τώρα δείχνουν στις αρχικές σελίδες)   |

Η φόρμα και ο χάρτης είναι σκόπιμα ασύνδετα: δεν θέλαμε ένα κουμπί που δείχνει
να λειτουργεί ενώ δεν στέλνει τίποτα, ούτε ένα κενό πλαίσιο χάρτη που απαιτεί
σύνδεση στο διαδίκτυο.

## Σχεδιαστικές σημειώσεις

**Το όνομα.** «ΟΚΤΩ», από το μέτρημα που προηγείται κάθε χορογραφίας: *5, 6, 7, 8*.
Η λωρίδα με τους οκτώ αριθμούς στην αρχική είναι το σήμα κατατεθέν της σελίδας —
τα τέσσερα τελευταία νούμερα ανάβουν με τη σειρά, όπως τα φωνάζει ο δάσκαλος.

**Το μετρικό.** Κάθε μάθημα δείχνει το μέτρο της μουσικής του (7/8 ο
καλαματιανός, 3/4 το μπαλέτο, 4/4 το hip hop). Δεν είναι διακόσμηση: είναι η
πληροφορία που ξεχωρίζει πραγματικά ένα είδος χορού από ένα άλλο.

**Χρώματα.** Βαθύ δαμασκηνί (`--ink`) για τη σβηστή αίθουσα, κιμωλία
(`--chalk`) για το φως, κεχριμπάρι (`--amber`) για τη ζελατίνα του προβολέα.
Το κεχριμπάρι χρησιμοποιείται ως χρώμα κειμένου **μόνο** πάνω σε σκούρο φόντο·
για ανοιχτό φόντο υπάρχει η πιο σκούρα εκδοχή `--amber-ink`.

**Γραμματοσειρές.** Δεν κατεβαίνει τίποτα από το διαδίκτυο. Οι στοίβες
γραμματοσειρών επιλέχθηκαν ώστε **κάθε επιλογή να έχει ελληνικά** — αλλιώς το
κείμενο θα έσπαγε σε άλλη γραμματοσειρά χωρίς να το καταλάβουμε.

**Κεφαλαία.** Οι μικρές ετικέτες είναι γραμμένες κεφαλαίες κατευθείαν στο HTML
(«ΜΑΘΗΜΑΤΑ») και όχι με `text-transform: uppercase`, ώστε να μη μένουν τόνοι.

**Προσβασιμότητα.** Ορατός δείκτης εστίασης, σύνδεσμος παράκαμψης στην αρχή,
σεβασμός στο `prefers-reduced-motion`, και όλα τα διαδραστικά στοιχεία
λειτουργούν με πληκτρολόγιο. Ο ιστότοπος διαβάζεται πλήρως και χωρίς JavaScript.
